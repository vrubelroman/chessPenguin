# ChessPenguin в браузере (подпроект)

Цель — версия программы, которая запускается в браузере на компьютере, как настольная: открыть PGN и
ChessBase, смотреть партии, анализировать движком, разбирать партию с !! и !. Телефоны и планшеты
получают страницу о приложениях (решения владельца — `docs/decisions.md`, «Веб-версия»).

Статус: **этап 1 сделан** (2026-10-30, ветка `web-app`): программа собирается для браузера и работает в
Firefox — открыть PGN кнопкой и перетаскиванием, примеры, партия, ходы, скачать PGN; страница для
телефонов и планшетов. Дальше — движок, разбор, «Мои партии» (этап 2). Задача — `docs/dev/tasks.md` §22.

- Архитектура, сборка, проверки, что дальше — `docs/dev/web.md` (разработчик).
- Код: `apps/web` (точка входа, страница `/app/`, `build.sh`, проверки в `check/`), слой платформы
  `apps/desktop/src/platform`, транспорт движка в браузере `crates/uci/src/worker.rs`.
- Интерфейс — `docs/design/web-version.md` (дизайнер).
- Концепция, аналоги — `docs/research/web-version.md` (аналитик); техническое исследование —
  `docs/research/web-version-tech.md`.

Сборка: `apps/web/build.sh` → `target/web/app/` (подробности — `docs/dev/web.md` §5).
